# Nexus Chat — Postman Testing Guide (API & Socket)

This guide walks you through testing both **`nexus-api`** (Go REST API) and **`nexus-socket`** (Elixir / Phoenix Socket.IO Gateway) located in `services/` using **Postman**.

---

## 1. Quick Architecture Summary

| Service | Directory | Tech Stack | Local Port | Protocol |
|---|---|---|---|---|
| **`nexus-api`** | `services/nexus-api` | Go 1.25 / Gin / pgx / sqlc | `8080` | HTTP / REST (`http://localhost:8080`) |
| **`nexus-socket`** | `services/nexus-socket` | Elixir / Phoenix OTP / Bandit | `3001` | Socket.IO v4 & HTTP Probes (`ws://localhost:3001` & `http://localhost:3001`) |

> **Authentication Key Note**: Both services use HMAC-SHA256 (HS256) JWTs. To allow tokens generated by `nexus-api` to authenticate directly in `nexus-socket`, start both services with the same `JWT_SECRET`:
> ```bash
> export JWT_SECRET="supersecret-dev-key"
> ```

## 3. Import Postman Files

Two ready-to-use Postman files are provided in the `postman/` folder:
1. **`postman/nexus_postman_collection.json`** — Full collection of REST requests and probes.
2. **`postman/nexus_postman_environment.json`** — Pre-configured environment variables.

### How to Import:
1. Open **Postman**.
2. Click the **Import** button in the top-left corner.
3. Drag and drop (or browse to select):
   - `postman/nexus_postman_collection.json`
   - `postman/nexus_postman_environment.json`
4. In the top-right corner of Postman, open the **Environment dropdown** and select:
   **`Nexus Local Environment`**.

## 4. Testing `nexus-api` (REST API)

The collection requests are arranged sequentially with automated post-response test scripts that save variables (`jwt_token`, `user_id`, `workspace_id`, `group_id`, `chat_id`, etc.) so subsequent requests run automatically without manual copy-pasting.

### Test Workflow:

1. **Verify Health Probes**:
   - Run `01 - Health & System Probes` -> `API: Health Check` -> **200 OK**.
   - Run `API: Readiness Probe (DB Check)` -> verifies PostgreSQL connection pool is healthy.
   - Run `Socket: Health Check` -> **200 OK** (`{"status":"healthy","service":"nexus-socket"}`).

2. **Register or Login**:
   - Run `02 - Authentication & Profile` -> `Register User` (`POST /api/auth/register`).
     - *Script automatically captures `jwt_token` and `user_id` into your Postman environment!*
   - Run `Get Profile (Me)` -> **200 OK** (verifies Bearer JWT authentication).

3. **Explore Workspaces & Groups**:
   - Run `03 - Workspaces` -> `List User Workspaces` -> captures `workspace_id`.
   - Run `04 - Groups & Channels` -> `List Groups in Workspace` -> captures `group_id` and default `chat_id`.

4. **Message History & User Discovery**:
   - Run `05 - Chats & Message History` -> `List Messages in Chat` (`GET /api/chats/{{chat_id}}/messages`).
   - Run `06 - User Discovery & Direct 1:1 Chats` -> `Search Users` (`GET /api/v1/users/search?q=test`).

## 5. Testing `nexus-socket` (Real-Time WebSocket)

Postman offers two ways to test WebSocket / real-time servers: **Native Socket.IO Request** (Postman v10+) or **Raw WebSocket Request**.

---

### Option A: Using Postman's Native Socket.IO Mode (Recommended)

1. In Postman, click **New** (or the `+` tab) and select **Socket.IO**.
2. **Server URL**: `ws://localhost:3001` (or `http://localhost:3001`).
3. **Configuration / Settings**:
   - **Version**: Select **v4** (Socket.IO client v4).
   - **Path**: `/socket.io` (default).
4. **Authentication (Handshake)**:
   - Go to the **Auth** tab (or **Handshake Payload**).
   - Enter the JSON payload referencing your Postman environment variable:
     ```json
     {
       "token": "{{jwt_token}}"
     }
     ```
5. **Set up Event Listeners** (in the bottom pane under **Events**):
   Add listeners for:
   - `new_message`
   - `user_joined`
   - `user_left`
   - `typing_indicator`
   - `message_reacted`
   - `message_updated`
   - `thread_reply`
6. Click **Connect**.
   - Status badge turns green: **Connected**.
7. **Test Emitting Client Events**:

   #### 1. Join Chat Room:
   - **Event Name**: `join_chat`
   - **Message (JSON)**:
     ```json
     {
       "chatId": "{{chat_id}}",
       "groupId": "{{group_id}}"
     }
     ```
   - Click **Send**.
   - Under Events, you will immediately see a `user_joined` broadcast received!

   #### 2. Send Message (with ACK):
   - **Event Name**: `send_message`
   - Check the **Acknowledgement (Ack)** box.
   - **Message (JSON)**:
     ```json
     {
       "chatId": "{{chat_id}}",
       "content": "Hello Nexus! Real-time message from Postman Socket.IO.",
       "tempId": "postman-temp-01"
     }
     ```
   - Click **Send**.
   - You will receive an Acknowledgement:
     ```json
     {
       "success": true,
       "messageId": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
       "status": "ok"
     }
     ```
   - And the `new_message` event listener will trigger with the broadcast payload!

   #### 3. Typing Indicator:
   - **Event Name**: `typing_start`
   - **Message (JSON)**: `{"chatId": "{{chat_id}}"}`
   - Click **Send**. Event listener `typing_indicator` receives `{"isTyping": true, ...}`.
   - Send `typing_stop` with `{"chatId": "{{chat_id}}"}` to cancel.

   #### 4. React to Message:
   - **Event Name**: `react_message`
   - **Message (JSON)**:
     ```json
     {
       "messageId": "<paste_message_id_from_ack>",
       "chatId": "{{chat_id}}",
       "emoji": "🔥",
       "action": "add"
     }
     ```
   - Click **Send**. Event listener `message_reacted` receives the reaction.

   #### 5. List Online Users:
   - **Event Name**: `get_online_users`
   - Enable **Ack**.
   - **Message (JSON)**: `{"chatId": "{{chat_id}}"}`
   - Click **Send**. The Ack returns the Delta-CRDT online presence list.

---

### Option B: Using Postman's Raw WebSocket Mode

If using Postman's Raw WebSocket request (`ws://`):

1. Click **New** -> **WebSocket**.
2. Set URL: `ws://localhost:3001/socket.io/?EIO=4&transport=websocket`
3. Click **Connect**.
4. You will receive the Engine.IO handshake frame:
   ```
   0{"sid":"...","upgrades":[],"pingInterval":25000,"pingTimeout":20000,"maxPayload":1000000}
   ```
5. In the message composer (Text), send the Socket.IO Auth frame:
   ```
   40{"token":"<paste_jwt_token_from_login_step>"}
   ```
6. The server will reply:
   ```
   40{"sid":"..."}
   ```
   *(You are now authenticated on the socket!)*
7. Send the `join_chat` frame:
   ```
   42["join_chat",{"chatId":"demo-room","groupId":"grp-demo"}]
   ```
8. Send a chat message with Ack ID `1`:
   ```
   421["send_message",{"chatId":"demo-room","content":"Hello via Raw WebSocket!"}]
   ```
   - You will receive:
     ```
     431[{"messageId":"...","status":"ok","success":true}]
     42["new_message",{"chatId":"demo-room","content":"Hello via Raw WebSocket!",...}]
     ```
9. Heartbeat: When the server sends ping `2`, reply with `3` to keep the connection alive.
